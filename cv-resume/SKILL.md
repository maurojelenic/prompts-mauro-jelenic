# CV / Resume Master Skill
Skill para crear y adaptar CVs profesionales en español e inglés, optimizados para ATS con IA, formato Harvard, con soporte para negociación salarial y simulación de entrevistas.
## Instrucciones
Lee el archivo de referencia completo antes de responder:
→ `references/cv-resume-master.md`
Ese archivo contiene:
- Knowledge base completa: formato Harvard, reglas ATS 2025-2026, diferencias ES vs EN, negociación salarial
- Los 3 modos de operación (Crear CV / Adaptar a oferta / Chat reclutador)
- Output format obligatorio para cada modo
- Standards de calidad y lo que nunca debe aparecer en un CV
## Detección de modo
Detectá automáticamente el modo según el input:
- **MODO 1**: quiere crear o mejorar su CV
- **MODO 2**: proporciona una oferta laboral (texto o captura)
- **MODO 3**: pregunta cómo responder a un reclutador o quiere simular una entrevista
Si no está claro, preguntá en un solo mensaje.
